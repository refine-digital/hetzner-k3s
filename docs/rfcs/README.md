## Creating a New RFC

1. Copy the [template](./template.md)
2. Name it `RFC-NNN-brief-description.md` (use next sequential number)
3. Fill in all sections
4. Share with team for review (allow 5 business days)
5. Update status based on decision

## RFC Process

```
Draft → In Review (5 days) → Decision Meeting → Accepted/Rejected
  ↓                                                      ↓
  └─────────────────────────────────────────→ Rejected
                                                         ↓
                                              Implementation → Archived
```
